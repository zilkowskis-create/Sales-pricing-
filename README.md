# Price List Analyzer V14

English GitHub Pages app for importing multiple Excel price lists, searching products and creating Excel quotations.

## V14 changes
- Each uploaded Excel file is shown as its own **Price list tab**.
- Only the sheets belonging to the selected price list are displayed below that tab.
- The **Price list** filter now filters by uploaded file, not by individual sheet.
- Sheet enable/disable actions affect only the currently selected price list.
- Existing quote, RAL/colour, images, Second Discount, filters and Excel export features remain available.


## V14 fix
- Price-list tabs and sheet selectors are rendered immediately after page load/reload.
- Header build marker changed to V14 so the deployed GitHub Pages version is easy to verify.
